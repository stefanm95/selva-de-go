# SELVA DE GO

## Project

Cinematic landing page for premium pet nutrition.

## Stack

- React
- Vite
- TailwindCSS
- Framer Motion
- Lenis

## Design Direction

NOT SaaS
NOT dashboard
NOT generic ecommerce

Inspired by:

- Shopify Shapes
- Vintage field guides
- National Geographic 1970s
- Explorer journals
- Collector editions
- Editorial storytelling

Keywords:

- retro 70s
- adventure
- field guide
- collectible archive
- premium
- tactile
- paper textures
- stamps
- expedition notes

## Navigation Philosophy

Opening Navigation:
large cinematic navigation

Site Navigation:
compact navigation after hero

Field Guide:
overlay navigation system

## Color System

Use CSS variables from globals.css.

Never introduce hardcoded brand colors if a token exists.

## Typography

Display:
Anton

Editorial:
Cormorant Garamond

Body:
Inter

Accent:
Staatliches

## Layout Rules

Spacing comes from components.

Never introduce global section padding.

SceneContainer controls width.

SceneColumn controls content width.

## Motion Rules

Subtle.

Editorial.

Avoid game-like motion.

Avoid large hover translations.

Avoid excessive blur.

Avoid parallax unless explicitly requested.

## Architecture Rules

Prefer extending existing components.

Avoid creating duplicate systems.

Avoid introducing new design systems.

Refactor before adding.
